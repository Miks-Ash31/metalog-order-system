
# METALOG — Metal Logistics and Order Management System

METALOG is a web-based order tracking and task management system developed for **Ara-midan Metal Fabrication Works**, a small-scale metal fabrication business based in Baguio City. This project is our final requirement for **Software Design**.

The system replaces the business's current paper-based logbook and receipt system with a digital platform that allows the Owner to log, track, and prioritize orders, and allows Workers to view and update the status of tasks assigned to them.

## The Problem

Ara-midan Metal Fabrication Works has relied on a fully manual, paper-based process since 1983. Because records are kept in a handwritten logbook, it's difficult to track order status, deadlines are sometimes missed, and the owner has no quick way to see which orders need immediate attention.

## Users

| User | Description |
|---|---|
| **Owner** | Accepts/declines orders, records specifications, negotiates pricing, assigns tasks, monitors progress, and releases completed orders. |
| **Worker** | Machinists, welders, and drivers (one account type, since the same staff perform multiple roles depending on the order). Views assigned tasks and updates task status. |
| **Customer** | Offline actor — communicates specifications to the Owner in person; does not have a system login. |
